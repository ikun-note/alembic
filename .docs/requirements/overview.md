# 需求总览

## 范围

本仓库是方案探究项目, 以 FastAPI + React 全栈参考应用为载体, 验证 Alembic 在 PostgreSQL 上的数据库管理与数据迁移. 产出为可运行代码与探究文档, 不承载真实生产业务.
